# 808Bay M-Dock releases

808Bay M-Dock の配布用リポジトリです (ソースコードは置いていません)。

最新版は [Releases](https://github.com/earnitcorporation-sudo/808bay-mdock-releases/releases/latest) からダウンロードしてください。

## はじめて使う方へ

1. [Releases](https://github.com/earnitcorporation-sudo/808bay-mdock-releases/releases/latest) の Assets から、最新版の zip (`808Bay-M-Dock-<版>.zip`) をダウンロードします。
2. zip を、日本語を含まない浅いフォルダ (例: `C:\mdock\`) に展開します。OneDrive の中は避けてください。
3. 展開したフォルダの `808Bay-M-Dock.exe` を起動します。別の窓 (worker) が一緒に開きますが、閉じないでください。
4. ブラウザに画面が開きます (開かない時は `http://127.0.0.1:8350` を開いてください)。
5. 最初に出る利用規約とプライバシーポリシーを読み、同意して進みます。
6. 「⚙️ 設定」→「🔑 メンバー認証」で **[Discord と連携]** を押します。先に運営の Discord サーバーでメンバーロールを付けてもらってください。
7. Chrome 拡張 (808Bay M-Dock Bridge) を使う場合は、`chrome://extensions` でデベロッパーモードを ON にし、展開したフォルダの `extension` を読み込みます。

起動時に「Windows によって PC が保護されました」と出た時は、「詳細情報」→「実行」で起動できます (コード署名を付けていないための表示です)。

PC の起動時に M-Dock を自動で立ち上げたい時は、zip 内の `README_FIRST.txt` の「PC の起動時に M-Dock を自動で起動する」の手順を見てください。

詳しい手順と更新のしかたは、zip 内の `README_FIRST.txt` と各リリースの説明にあります。
